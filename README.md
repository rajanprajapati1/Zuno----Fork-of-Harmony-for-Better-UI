# 🚀 Welcome to Zuno

**Zuno** is a professional fork of Harmony Music, reimagined with a focus on premium aesthetics, a modern user interface, and improved stability.

## ✨ Highlights
- **Official Rebranding**: Fully transitioned the application identity to **Zuno**.
- **Modern UI Architecture**: Introduced a sleek, modern side navigation bar for a more intuitive and premium desktop experience.
- **Enhanced Home Screen**: Resolved a major caching issue. The home screen now correctly displays all content sections (Quick Picks, Favorites, Albums, Artists, and Playlists) immediately upon launch.

## 🛠️ Bug Fixes & Technical Improvements
- **Installer Rectification**: Fixed the Windows installer configuration to correctly create a `Zuno` installation directory.
- **System Stability**: Resolved critical JNI plugin build errors on Windows by optimizing the CMake configuration and Java environment handling.
- **Cache Migration (V4)**: Implemented a robust cache invalidation system to ensure all users receive the latest UI updates and content sections without manual intervention.

## 💾 Installation (Windows)
1. Download `zuno-setup-1.12.2.exe` from the assets below.
2. Run the installer to set up Zuno on your system.
3. Launch and enjoy your music with a superior interface!
